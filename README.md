QSR Tracker Backend

QSR Tracker Backend is the data relay for the restaurant industry tracker. It is for the tracker app, which needs market, filing, and news data in one place.

It relays SEC filings, economic data, tariff watch, industry magazine news, food network news, stock history, futures prices, and congressional trading disclosures. A shared quote relay stretches free data limits across visitors. It also syncs data between devices and holds the trading engine routes for snapshots, ledger, heartbeat, and commands.

This app is checked every morning by Control Troll.

Latest change. Added engine routes for a snapshot, a ledger, a heartbeat, and a two way command queue.
